## 什么是回程路由，为什么它比“机房位置”更重要

“回程”指的是数据从 VPS 返回用户所在地的路径。

举个简单例子：

- 你在上海联通网络上访问洛杉矶 VPS；
- 请求从上海发往洛杉矶，这部分属于去程；
- VPS 返回网页、文件或视频数据到上海，这部分属于回程。

很多测速文章只展示单方向结果，但用户体验往往同时受到两个方向影响。一个线路即使去程看起来不错，回程出现绕路、拥堵或丢包，网页打开速度仍然可能不理想。

常见的网络名称可以这样理解：

| 名称 | 常见含义 | 主要关注点 |
| --- | --- | --- |
| AS4134 | 中国电信传统 ChinaNet/163 网络 | 价格低、容量大，但高峰期可能拥堵 |
| AS4809 CN2 GT | 中国电信 CN2 Global Transit | 通常比普通 163 更好，但不等于 CN2 GIA |
| AS4809 CN2 GIA | 中国电信高质量国际网络 | 稳定性和线路质量通常更受重视，成本也更高 |
| AS23764 CTGNet | 中国电信另一类国际互联网络 | 官方将其描述为在实际表现和成本上接近 CN2 GIA |
| CMIN2 | 中国移动国际优质线路 | 对中国移动用户的跨境连接较有参考价值 |
| Premium China Unicom | 中国联通优质互联 | 用于改善中国联通方向的跨境连接 |

搬瓦工官方说明，普通 AS4134 网络在高峰时段可能出现拥堵，而 CN2 GIA 的定位是提供更稳定的中国方向连接。官方同时也提醒，CN2 GIA 的容量有限，并不适合简单理解成“任何情况下都不会丢包”。

## 如何自己检查搬瓦工回程路由

只看宣传页面不够。购买或迁移前，建议至少从自己的网络环境做一次测试。

### 1. 用 traceroute 或 tracert 看路径

Linux 或 macOS 可以使用：

bash
traceroute -T -p 443 your-server-ip


也可以使用更常见的 TCP 路由追踪工具：

bash
mtr -rwzc 100 your-server-ip


Windows 可以使用：

powershell
tracert your-server-ip


如果要观察中国大陆方向的回程，单纯在 VPS 上执行 `traceroute` 只能看到从 VPS 到目标地址的路径。更完整的做法是：

- 在 VPS 上准备测试文件或测试端口；
- 从中国电信、联通、移动网络分别测试；
- 使用多个地区的探针进行 TCP、UDP 或 ICMP 路由追踪；
- 在白天和晚高峰各测一次。

### 2. 不要只看某一个中间节点的丢包

MTR 中间节点显示丢包，不一定代表最终连接真的丢包。有些路由器会限制 ICMP 响应，但会正常转发业务流量。

更应该关注：

- 丢包是否持续到最后一跳；
- 最后一跳的平均延迟；
- 延迟是否在高峰期明显抖动；
- TCP 443 端口的实际连接速度；
- 下载速度是否与端口上限相匹配。

如果只有某个中间节点显示 20% 丢包，但后续节点和最终目标没有明显丢包，通常不能直接判定整条线路有问题。相反，如果从多个测试点到最终服务器都出现持续丢包，就需要认真考虑线路质量。

### 3. 去程测试和回程测试要分开看

很多文章标题写着“三网回程”，实际展示的却是从中国到 VPS 的去程路由。两者方向不同，不能直接互换。

比较时最好明确记录：

- 测试方向；
- 测试运营商；
- 测试城市；
- 测试时间；
- 目标 IP；
- 是否经过代理或中转；
- 测试使用的协议和端口。

如果你使用的是 VPS 搭建网站或 API，TCP 443 的测试通常比只看 ICMP Ping 更有参考意义。如果是数据库同步、远程桌面或长连接服务，还要关注连接稳定性和抖动，而不只是平均延迟。

## 哪个套餐更适合测试回程路由

如果你的目标只是确认线路，而不是马上承载高流量业务，没有必要一开始就购买高配套餐。

### 个人博客或小型网站

1 GB 或 2 GB 配置通常足够用于：

- 静态网站；
- 轻量级博客；
- 小型 API；
- 测试 Nginx、Docker 或面板；
- 观察不同机房的路由表现。

这类场景更需要关注月流量和线路稳定性。2.5 Gbps 端口速率听起来很大，但端口上限不等于你一定能长期跑满。实际速度还会受到跨境线路、服务器负载、磁盘读写和对端网络影响。

### WordPress 或中小型应用

4 GB 或 8 GB 方案更适合运行：

- WordPress；
- 小型电商站；
- 数据库和应用服务；
- 多个 Docker 容器；
- 有一定访问量的 API。

如果访客主要来自中国大陆，优先确认目标机房的电信、联通和移动方向，而不是只看内存是否够用。配置再高，回程拥堵时也不能自动变成高速线路。

### 下载、回源或大文件传输

8 GB 以上的方案通常拥有更高月流量和端口速率，更适合：

- 大文件分发；
- 图片或视频回源；
- 备份同步；
- 多用户下载；
- 对带宽有要求的业务。

不过，CN2 GIA 线路本身容量有限，官方也指出其成本高、资源紧张，并且不适合承受持续的大规模攻击。

如果业务需要持续高并发下载，建议先确认服务条款、流量政策和实际出口能力，不要只根据套餐页面上的“10 Gbps”做容量规划。

## 购买时如何避免选错回程线路

### 不要把“CN2”三个字当成完整答案

CN2 GT 和 CN2 GIA 并不是同一个概念。普通宣传中经常把它们放在一起，但线路质量、拥堵情况和价格定位可能不同。

如果你的关注点是中国大陆方向稳定性，至少要继续确认：

- 是 CN2 GT 还是 CN2 GIA；
- 是去程还是回程；
- 是哪一家运营商；
- 是否包含中国移动和中国联通方向优化；
- 当前套餐能否使用目标机房。

### 不要只依据旧测评选择机房

线路会扩容、调整，也会因为运营商互联关系变化而改变。第三方文章可以帮助你理解 DC6 和 DC9 的历史差异，但不能代替当前测试。

搬瓦工在 2024 年 11 月宣布，CMIN2 已启用在 `USCA_6` 和 `USCA_9` 的 E-Commerce VPS 上。这个变化说明，同一个机房的线路能力也可能随着网络升级发生变化。

### 不要忽视 IP 和目标地区

即使机房相同，不同 IP 段的路由也可能存在差别。你可以在购买后先测试：

- 北京电信；
- 上海联通；
- 广州移动；
- 你业务真实用户所在的地区。

如果测试结果和预期差距较大，再考虑迁移机房或更换服务方案。官方页面说明，洛杉矶相关服务支持在数据中心之间迁移，迁移前仍应确认具体套餐和目标位置是否可用。

## 常见问题

### 搬瓦工 DC9 一定比 DC6 快吗？

不能绝对这么说。官方当前更强调 USCA_9 的整体网络容量和稳定性，但实际速度仍然取决于运营商、城市、时间段、IP 和服务器负载。对电信用户来说，二者都需要通过实际回程测试判断。

### 搬瓦工回程路由能不能自己修改？

通常不能手动指定某一条运营商路径。你可以选择支持相应线路的套餐和机房，也可以在允许的情况下迁移数据中心，但具体路由由网络运营商和上游互联决定。

### CMIN2 对中国移动用户有用吗？

CMIN2 是中国移动国际方向的网络名称。搬瓦工官方表示，CMIN2 已启用在 USCA_6 和 USCA_9 的 E-Commerce 方案上。对中国移动用户来说，这比只看电信 CN2 GIA 更有参考价值，但最终仍应通过实际测试确认延迟和丢包。

### 回程路由和延迟哪个更重要？

两者都重要，但用途不同：

- 普通网页访问：看延迟、丢包和 TCP 连接速度；
- 远程桌面：看延迟、抖动和持续稳定性；
- 文件传输：看丢包、带宽和晚高峰吞吐量；
- API 或数据库：看连接稳定性、重传和长时间运行表现。

低延迟不代表一定高吞吐，高带宽也不代表跨境方向一定稳定。

### 选择搬瓦工时应该先看配置还是线路？

如果用户主要在中国大陆，建议先确认线路和机房，再比较 CPU、内存和磁盘。服务器配置不足会拖慢应用，但线路方向不合适，同样会让访问体验变差。

## 最后的选择建议

如果你只是想找一台面向中国大陆访问较友好的 VPS，建议按这个顺序做决定：

1. 先确认业务用户主要使用电信、联通还是移动；
2. 优先查看是否包含 CN2 GIA、CMIN2 和 Premium China Unicom；
3. 在 DC6 与 DC9 之间，先把 USCA_9 作为默认候选；
4. 如果需要更高带宽，再比较 DC6 和 DC9 的实际端口、流量与测试结果；
5. 购买后从真实用户地区测试回程，而不是只看宣传页面；
6. 在白天和晚高峰分别测试；
7. 只有当最终一跳持续丢包或高峰期明显恶化时，才考虑迁移机房。

搬瓦工回程路由真正值得看的，不是某个机房编号听起来够不够“高级”，而是你的运营商到目标服务器之间是否有稳定、可用、适合业务的路径。先确定使用场景，再看线路和套餐，通常比直接追逐某个热门缩写更不容易买错。
